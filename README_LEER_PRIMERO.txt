JYM ALLGRAPHICS — COPIA DEL SITIO PUBLICO (08/11/2026)
=======================================================

NO TENES QUE DESCARGAR PYTHON NI EJECUTAR ARCHIVOS .BAT

PARA VER LA PAGINA:
1. Descomprimir el ZIP.
2. En Visual Studio Code: Archivo > Abrir carpeta. Elegir JYM_ALLGRAPHICS_WEB_ORIGINAL_VSCODE.
3. Hacer clic derecho sobre index.html (de la carpeta principal).
4. Seleccionar "Open with Live Server".

O podes simplemente hacer doble clic sobre index.html para abrirlo en el navegador.

¿QUE CONTIENE?
- index.html: portada REAL de Tiendanube, adaptada solo para uso local.
- productos/index.html: listado REAL de productos.
- insumos/: categorias reales de insumos (toner, cartuchos, fusores, drum, chips, etc.).
- contacto/index.html y quienes-somos/index.html.
- productos/toner-alternativo-hp-laserjet-m552-mfp-m577-m553dn-508x/index.html.
- assets/css/: archivos CSS reales del tema Toluca, descargados de la CDN de Tiendanube.
- assets/js/: JavaScript publico real de Tiendanube.
- CSS_PERSONALIZADO.css: agrega tus cambios aqui, sin alterar los archivos originales.
- FUENTES_ORIGINALES/: HTML original de cada pagina SIN MODIFICAR (para comparar).
- INVENTARIO.json: detalle de la descarga.

IMPORTANTE:
Los HTML reproducen las paginas descargadas (16 en total). Para que se vean correctamente, la computadora necesita INTERNET: las fotografias, fuentes y ciertos scripts todavia se cargan desde los servidores de Tiendanube. El codigo interno de administracion, el checkout, cuentas, ventas, stock y APIs no se puede clonar desde una pagina publica; las funciones dinamicas no estan garantizadas.

Los enlaces a las paginas incluidas abren la copia local; otros enlaces pueden llevar al sitio de produccion. No confirmes compras ni completes formularios pensando que son de prueba.

ESTO NO ES UN REDISEÑO. La carpeta de FUENTES_ORIGINALES permite verificar que se utilizo la web publicada.

COMO CAMBIAR LA APARIENCIA:
Agregar CSS al archivo CSS_PERSONALIZADO.css. Los index.html lo incluyen al final de sus estilos. Tambien podes editar los archivos HTML y assets/css directamente. Los cambios solo modifican tu carpeta local.
